# ILI v0.5: release-date as-of replay and matched revised-data control

Protocol fixed before any model training/performance calculation for this stage. User authorized actual historical-vintage backtesting, comparisons, preservation and ZIP. Data-availability reconnaissance found 212,710 records from ten regional queries, no null release dates or duplicate (region,epiweek,issue) keys; early summer observations often first appear in later backfills. No performance-driven sample or method selection.

## Archive and availability

Official Delphi legacy FluView vintage records, observation weeks 201040–201939, issues 201001–201952, one HHS region per query. Public anonymous API permits two multiselect parameters; use epiweeks and issues, keep region singular, ten queries and <=2 concurrent requests. Do not bypass authentication/rate limits. Initial three-multiselect query returned 401; the official documented anonymous syntax resolved it. System curl verifies TLS using system trust; Python urllib's local certificate-chain failure is not handled by disabling verification. Preserve compressed raw responses, metadata, hashes, download failure log and normalized fields. Reproduction defaults to cached records, no implicit network update.

Availability is release_date <= issuance cutoff. For each region/week retain the latest release_date, breaking same-date ties by largest issue. Filter release dates BEFORE choosing a vintage; never choose an issue whose release is later than cutoff. Date-only fields cannot resolve intraday publication times; all cutoffs mean end-of-day. This is Delphi archive-available replay, not proof of the exact historical CDC/web/API delivery state. Archive incompleteness and replacement of intraday versions cannot be excluded.

## Issuance schedule and horizon

Retain original 12 observed weeks ending origin t and target t+2 using CDC weeks. Issue at end of Saturday t+1 (origin week-end +7 calendar days), after ordinary Friday reporting. Target ends seven days after issuance, not fourteen: this preserves the original observation-week horizon while making reporting lag explicit. Do NOT call it two weeks ahead from real release time. Archive rows with missing/invalid release date are excluded; never infer Friday availability from issue codes. Earlier summer gaps are not filled from future revisions.

Use six original outer seasons 2013–14…2018–19. Model-selection training cutoff is first scheduled issuance of the preceding validation season; final refit/calibration cutoff is first scheduled issuance of outer season. These cutoffs are fixed even if early seasonal forecasts are unavailable. Training/validation/refit membership retains origin and target both inside the original rolling stage ranges. Target labels for selection and residual calibration are the versions available by final refit cutoff; training labels and historical predictors use the relevant fit-cutoff snapshot. Actual validation/test predictors use their individual issuance-date snapshots. Target outcomes of the outer test do not enter fitting, selection or residual estimation.

At each training stage, historical features may use revisions already known at that model's fit time (ordinary real-time retraining convention). No requirement to train on immutable first-release values. Standardization uses unique available region/week observations in that stage's training range. Inference has no y_true argument. Validation outcomes select the original Ridge grid and LSTM stopping epoch only at final selection time before outer evaluation; validation predictions are not claimed to be historically deployed predictions of a parameter configuration not yet selected.

## Eligibility and comparator

Require all 12 consecutive feature weeks for all ten regions at each forecast cutoff. Training/refit also require target labels at their fit cutoff. Validation requires target labels at outer refit cutoff. Keep complete ten-region origin groups, exclude unavailable groups and save exact reasons/counts. Seasonal baseline uses only prior-season same target-week observations at its fit cutoff, with original week53 fallback to available weeks52/1; if a required reference is absent, exclude that origin for all five methods and both regimes. No interpolation or carry-forward of missing observation weeks. Existing as-of values may be stale relative to later revisions, which is intentional.

Two new regimes share exact train/validation/refit/test window IDs, scaler observation IDs, forecast schedule, feature definitions, candidate grids, seeds and model classes: (1) AsOf uses availability-constrained values/labels; (2) MatchedRevised substitutes values from the original 2026-10-20 data snapshot on exactly these keys. Seasonal references use identical historical observation keys in both regimes. Hyperparameters are selected separately on each regime's validation data; differences therefore describe the total pipeline effect of revisions, not a fixed-parameter causal effect. MatchedRevised is a hindsight counterfactual, not deployable. A third OriginalFrozen context table reuses v0.2 point and v0.4 probability predictions on the new common test subset; training/selection history differs, so it is not the controlled comparison.

## Models and probability forecasts

Reuse unchanged rolling.model definitions, full seven-value Ridge alpha grid [.1,1,10,100,1000,10000,100000], fixed HGB, small LSTM max60 epochs, existing early stopping, CPU<=4 threads and seed2026. Fit selection models on prior training seasons, select on preceding validation season, refit fixed choices on all eligible pre-test history. Freeze weights and empirical residual quantiles for each entire outer season. Persistence and Seasonal also respect vintage availability. No test-based model revision.

Use the v0.4 residual wrapper: same fixed 23 quantiles, linear empirical quantiles of pooled previous-validation residuals, add to current point predictions, clip to [0,100]. AsOf residual labels use versions available at outer refit time; MatchedRevised labels use fixed final snapshot. The validation set also selects hyperparameters, so calibration is not independent; transport from selection model to refit model is an assumption. Original v0.3 isotonic fits do not modify forecasts.

## Evaluation and interpretation

Freeze all twelve regime/fold outputs before joining test truth. Score both regimes and OriginalFrozen against the same frozen revised 2026-10-20 outcomes, explicitly an evaluation reference rather than claim of immutable ground truth. Report point Macro-MAE, pooled RMSE, bias, WIS, median MAE/RMSE/bias, 50/80/95% coverage and widths, overall/by season/by region. Report AsOf minus MatchedRevised differences on identical samples; lower errors/WIS are better. Use unchanged independently tested WIS formula and 23 levels. No new bootstrap or confidence intervals: previous indices assume consecutive complete seasons, while this phase may have gaps. No unsupported significance or future-season generalization claims. Report eligibility rate, date/lags, initial versus final observation revisions and the effect of revised labels/predictors.
