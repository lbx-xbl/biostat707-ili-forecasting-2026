# ILI v0.4 — Probabilistic forecasts and WIS

This completed extension implements the professor's **residual quantile** option. It estimates 30 historical residual distributions (six outer seasons × five methods), produces 23 quantiles for each of 15,050 matched forecasts, and evaluates WIS, coverage, widths and conditional score differences. Original point models are not retrained; all v0.1–v0.3 artifacts and archives are preserved byte-for-byte. See `outputs/probabilistic_v0_4/probabilistic_report.html` for the self-contained English report, Chinese interpretation and seven embedded figures.

## Method and temporal boundaries

The input for each residual distribution is the immediately preceding validation season's saved predictions, generated by models fit on earlier seasons. Pool residuals equally across the ten HHS regions; take fixed linear empirical quantiles; add to the frozen outer point predictions; clip to [0,100]. The median may change, so all new median metrics are separate from the old point-forecast metrics. All residual target weeks precede every outer origin week. No current-test labels enter distribution fitting or forecast construction, and there is no tuning of residual scale or grouping.

The previous validation season also selected Ridge alpha and LSTM epoch. It is not an independent calibration sample, and the final refit point model has more training history than the residual-producing model. Residual transport, common regional variance and stationarity are assumptions, not guarantees. Do not describe the intervals as conformal intervals or guarantee nominal coverage. Revised historical data and already-viewed point results make this exploratory retrospective analysis, not real-time or untouched confirmation.

WIS uses 11 central intervals with alpha=0.02,0.05,0.10,0.20,...,0.90 plus median, weights alpha/2 and 0.5, denominator 11.5. It equals twice mean pinball loss over 23 levels. Four saved components sum to WIS: weighted widths, below-lower penalties (overprediction), above-upper penalties (underprediction), and the median absolute-error term. Macro-WIS weights regions equally; with complete panels this equals pooled mean. Median RMSE pools squared errors. Coverage includes both endpoints. Mean width must be interpreted alongside coverage and WIS.

Bootstrap comparisons reuse the exact v0.3 season-stratified, paired moving-block draws (5,000 replicates; eight-week primary, four/thirteen-week sensitivity). All models/regions share sampled weeks. Report original WIS differences, marginal percentile intervals and centering shifts. These condition on fitted point models and residual distributions; they exclude their estimation/selection uncertainty and do not generalize to unobserved seasons. Nonstationarity, shared training, beyond-block dependence and edge-week underweighting limit coverage claims. No multiplicity-adjusted testing or learned-model pairwise ranking inference is performed.

## Actual results (six test seasons)

| Method + residual distribution | Macro-WIS | Reduction vs probabilistic Persistence | 95% interval coverage |
|---|---:|---:|---:|
| Persistence | 0.292567 | — | 93.92% |
| Seasonal | 0.389323 | -33.07% | 91.33% |
| Ridge | 0.246630 | 15.70% | 93.75% |
| HGB | 0.238286 | 18.55% | 94.12% |
| LSTM | 0.248713 | 14.99% | 92.52% |

All three learned methods have WIS difference intervals below zero versus probabilistic Persistence at all predeclared lengths; this is conditional descriptive evidence, not a universal ranking. HGB has the lowest observed WIS; point RMSE favored Ridge in v0.2. Scores assess different aspects, and probability forecasts include a residual wrapper. Overall coverage can hide substantial season/region differences; inspect the full report.

## Reproduction

Run from the project directory; retain the ZIP's relative layout, including prior archives beside the project directory. The existing `.venv` is not packaged. On a fresh machine:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q tests tests_rolling tests_diagnostics tests_probabilistic
.venv/bin/python run_probabilistic.py --config config/probabilistic.json --output-dir outputs/probabilistic_reproduction
.venv/bin/python verify_probabilistic.py --output-dir outputs/probabilistic_reproduction
```

Tested on the existing Python 3.11.5 macOS arm64 environment, maximum four compute threads. Analysis requires no network downloads and no model loading/training. A nonempty output directory is rejected. For report-only regeneration:

```bash
MPLCONFIGDIR=.cache/probabilistic-matplotlib .venv/bin/python -c "from probabilistic.report import render; render('outputs/probabilistic_v0_4')"
```

The verifier independently interpolates sorted residual order statistics, recomputes WIS using pinball loss, checks every interval and grouped summary, and recomputes all bootstrap differences by direct indexing. It verifies source hashes, temporal boundaries, actual-label perturbation invariance and prior artifact preservation. Verification code uses assertions: run Python normally, **not** with `-O`.

## Artifacts

- `inputs/`: byte-identical source validation/outer forecasts and selection metadata for every fold, original point predictions and prior bootstrap indices.
- `residual_quantiles.csv`: 690 residual quantile estimates with source dates and counts; the fitted probabilistic model parameters.
- `validation_residuals.csv`: 15,050 historical residual rows; model/season provenance retained.
- `temporal_audit.csv`, `forecast_freeze.json`, `input_manifest.json`, frozen config/protocol: timing boundary and hash records.
- `quantiles_before_evaluation.csv`, per-fold equivalents: wide forecasts saved before joining outer labels.
- `quantiles_wide.csv`, `quantile_predictions.csv`: wide and 346,150 long-form quantile predictions; raw/projected values, original points and evaluation outcomes.
- `scores.csv`: 15,050 WIS values/components and median errors.
- `interval_scores.csv`: 165,550 interval scores, widths, coverage and tail indicators.
- `metrics.csv`, `coverage.csv`, `quantile_reliability.csv`: 85 aggregate metric rows, 935 interval summaries, 1,955 quantile reliability frequencies.
- `clipping_summary.csv`: support projection counts by fold/model.
- `wis_bootstrap_intervals.csv`: 204 overall/region/season intervals across three lengths; `wis_bootstrap_replicates_L*.npz`: 1,020,000 paired differences. NPZ axes are replicate × group × comparator, with named groups/scopes/models.
- `probabilistic_report.html`, `figures/`: self-contained report and seven scientific plots.
- `run_summary.json`, `verification_summary.json`, `review_summary.txt`, `execution_log.txt`: actual execution, checks and independent review. ZIP extraction checks and SHA-256 are saved beside the archive.
